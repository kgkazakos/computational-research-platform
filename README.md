# Computational Research Platform

A unified monorepo for automating the science of User Insight and AI Alignment.

## 🚀 Mission
To bridge the gap between **Mixed-Methods Research** and **AI Engineering**. This platform contains a suite of agentic tools designed to simulate, measure, and align AI models to human intent at scale.

## 🛠 Tech Stack
* **Intelligence:** Google Gemini 3 Pro (Long Context Reasoning) & Flash (Speed).
* **Orchestration:** LangGraph (State Machines) & DSPy (Prompt Optimization).
* **Interface:** Next.js 15, React Flow, Vercel AI SDK.
* **Infrastructure:** Supabase (pgvector), Vercel, Google Cloud Vertex AI.

## 📂 Project Roadmap
| ID | Project Name | Description | Status |

| **P1** | **Reasoning-First RAG** | An MCP Server that uses Long-Context Gemini to answer research questions with chunk-level citations. | 🚧 In Progress |
| **P2** | **Synthetic User Council** | Multi-agent consensus system simulating diverse stakeholder personas debating product feedback. | 📅 Planned |
| **P3** | **Red Team Agent** | Video-first agent that detects UX friction and safety risks from screen recordings. | 📅 Planned |
| **P4** | **Adaptive Voice UI** | Real-time multimodal voice interface that handles interruption and turn-taking. | 📅 Planned |
| **P5** | **Co-Reasoning Canvas** | Spatial interface where AI generates hypotheses and connects insights on an infinite canvas. | 📅 Planned |
| **P6** | **Alignment Workbench** | Dashboard for fine-tuning Reward Models on personal research preferences. | 📅 Planned |
